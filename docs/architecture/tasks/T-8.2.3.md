# README.md

# Lumos - AI Work Assistant

Lumos is an AI-powered desktop assistant for macOS that automates repetitive tasks, delivers instant insights, and streamlines workflows.

## Features

- **Governed AI Operations**: AI proposes, you approve, system enforces
- **Progressive Trust**: Earn automation privileges per operation
- **Audit Trail**: Complete history of all actions
- **MCP Integration**: Extensible tool ecosystem

## Installation

1. Download Lumos.dmg from releases
2. Open DMG and drag Lumos to Applications
3. Launch Lumos
4. Grant necessary permissions

## Requirements

- macOS 13.0 or later
- Ollama installed (for local AI)
- 8GB RAM minimum

## Getting Started

See [User Guide](docs/user-guide.md) for detailed instructions.
