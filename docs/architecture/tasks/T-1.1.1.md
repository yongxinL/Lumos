```typescript
// tests/setup/smoke.test.ts
import { describe, it, expect } from 'vitest';
import { existsSync } from 'fs';
import { resolve } from 'path';

describe('Project Setup Smoke Tests', () => {
  it('should have package.json with required fields', async () => {
    const pkg = await import('../../package.json');
    expect(pkg.name).toBe('lumos');
    expect(pkg.main).toBeDefined();
```

## Implementation Steps

1. **Initialize project**

   ```bash
   mkdir lumos && cd lumos
   pnpm init
   ```

2. **Install dependencies**

   ```bash
   pnpm add react react-dom
   pnpm add -D electron typescript vite @vitejs/plugin-react electron-builder eslint prettier husky @types/node @types/react @types/react-dom
   ```

3. **Create TypeScript configs** (tsconfig.json, tsconfig.main.json, tsconfig.renderer.json)

4. **Create Vite config** (vite.config.ts)

5. **Create ESLint config** (eslint.config.js)

6. **Setup Husky**

   ```bash
   pnpm exec husky init
   echo "pnpm lint-staged" > .husky/pre-commit
   ```

7. **Create project structure** (src/main, src/renderer, src/types)

8. **Create entry points** (src/main/index.ts, src/renderer/main.tsx)

9. **Add npm scripts to package.json**

10. **Verify with `pnpm dev`**
