## Technical Notes

### Core Interface

```typescript
interface PolicyEngine {
  evaluate(proposal: ActionProposal, context: EvaluationContext): PolicyResult;
  findMatchingSkills(operation: OperationType): Skill[];
  resolveConflicts(skills: Skill[], proposal: ActionProposal): Skill | ConflictResolutionRequired;
}

interface EvaluationContext {
  user_id: string;
  trust_levels: Map<OperationType, TrustLevel>;
  active_skills: Skill[];
  active_policies: Policy[];
}

interface PolicyResult {
  allowed: boolean;
  requires_confirmation: boolean;
  matched_skill: SkillReference | null;
  rule_references: string[];
  denial_reason?: string;
  trust_level_used: TrustLevel;
}
```

### Evaluation Algorithm

```typescript
function evaluateProposal(proposal: ActionProposal, context: EvaluationContext): PolicyResult {
  // Step 1: Find matching skills by operation type
  const matchingSkills = context.active_skills.filter(
    (skill) => skill.status === 'active' && skill.enabled_operations.includes(proposal.operation)
  );

  // Step 2: No skills = DENY (fail-safe)
  if (matchingSkills.length === 0) {
    return denyResult(`No skill defines operation: ${proposal.operation}`);
  }

  // Step 3: Sort by priority (descending)
  const sortedSkills = matchingSkills.sort((a, b) => b.priority - a.priority);

  // Step 4: Evaluate each skill in priority order
  for (const skill of sortedSkills) {
    const result = evaluateSkill(skill, proposal, context);
    if (result.passed) {
      return approveResult(skill, result.rule_references, context);
    }
  }

  // Step 5: All skills failed = DENY
  return denyResult('All matching skills failed policy constraints');
}
```

### Fail-Safe Design

**Critical Requirement:** Policy engine crash MUST result in action denial.

```typescript
function safeEvaluate(proposal: ActionProposal, context: EvaluationContext): PolicyResult {
  try {
    return evaluateProposal(proposal, context);
  } catch (error) {
    // Log error for debugging
    logger.error('Policy engine crash', { error, proposal_id: proposal.id });

    // ALWAYS deny on error - fail-safe
    return {
      allowed: false,
      requires_confirmation: false,
      matched_skill: null,
      rule_references: ['POLICY_ENGINE_ERROR'],
      denial_reason: 'Policy engine error - action blocked for safety',
      trust_level_used: 'OBSERVE',
    };
  }
}
```

### Performance Optimization

- Pre-compile constraint expressions at skill load time
- Cache skill matches by operation type
- Early exit on first passing skill
- Index skills by operation type for O(1) lookup

### Trust Level Confirmation Logic

```typescript
function determineConfirmationRequired(
  skill: Skill,
  proposal: ActionProposal,
  context: EvaluationContext
): boolean {
  const trustLevel = context.trust_levels.get(proposal.operation) || 'OBSERVE';

  // OBSERVE: Always requires confirmation
  if (trustLevel === 'OBSERVE') return true;

  // SUPERVISED: Always requires confirmation
  if (trustLevel === 'SUPERVISED') return true;

  // DELEGATED: Auto-execute, but high-risk still requires confirmation
  if (trustLevel === 'DELEGATED') {
    return proposal.risk_level === 'high';
  }

  return true; // Default: require confirmation
}
```

## Security Considerations

1. **No LLM involvement** - All evaluation is deterministic TypeScript
2. **Fail-safe on error** - Any exception results in DENY
3. **Audit all decisions** - Rule references enable audit trail
4. **No bypass path** - All proposals MUST go through policy engine
5. **Trust level enforcement** - Cannot execute without sufficient trust
